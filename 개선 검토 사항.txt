vLLM의 OpenAI 호환 엔드포인트는 response_format으로 JSON Schema 강제를 지원하므로, /chat/ 핸들러에서 받은 값을 vLLM 호출에 얹기만 하면 됩니다:
python# UNI RAG /chat/ 핸들러 내부 (개념 샘플)
class ChatRequest(BaseModel):
    query: str
    model_key: str
    history: list = []
    stream: bool = False
    guided_json: dict | None = None   # ← 추가 필드

def build_vllm_payload(req: ChatRequest, messages):
    payload = {
        "model": req.model_key,
        "messages": messages,
        "stream": req.stream,
    }
    if req.guided_json:
        payload["response_format"] = {   # vLLM 0.6+ OpenAI 호환 방식
            "type": "json_schema",
            "json_schema": {"name": "edit_spec", "schema": req.guided_json},
        }
        # (구버전 vLLM이면 대신: payload["guided_json"] = req.guided_json)
    return payload
vLLM 버전에 따라 response_format 방식(신)과 guided_json extra body 방식(구)이 갈리니, 서버의 vLLM 버전 확인을 요청 사항에 포함하세요. RAG 검색 파이프라인은 건드리지 않고 최종 생성 호출에만 얹는 변경입니다.
